# Mavishim ses kayıtları

Sesleri `.mp3`, `.ogg` veya `.wav` olarak bu klasöre koyun. Her satırdaki
dosya adı uygulamanın ses altyapısının beklediği addır. Aynı türden birden
fazla kayıt koymak için `*_01`, `*_02`, `*_03` düzenini kullanın.

Örnekler:

- `ui_tap_01.mp3`, `ui_tap_02.mp3`, `ui_tap_03.mp3`
- `ui_back_01.mp3`, `game_win_01.mp3`, `game_lose_01.mp3`
- `game_tension_01.mp3`, `menu_music_01.mp3`

Kayıtlar eklenene kadar uygulama ses isteğini güvenle görmezden gelir.
